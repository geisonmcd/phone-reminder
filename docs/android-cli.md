# Android CLI

O **Android CLI** (Command-Line Interface) é a ferramenta de linha de comando oficial do Google para desenvolvimento Android. Ele permite executar tarefas de desenvolvimento diretamente do terminal, sem precisar abrir o Android Studio.

## Principais usos

- **Criar projetos** – Gerar novos apps Android com templates predefinidos
- **Gerenciar emuladores** – Criar, iniciar e configurar dispositivos virtuais (AVDs)
- **Construir apps** – Compilar, testar e empacotar APKs/AABs
- **Gerenciar SDK** – Instalar, atualizar e remover pacotes do Android SDK
- **Depuração e logs** – Acessar logs do dispositivo, instalar apps, executar shell commands
- **Integração CI/CD** – Automatizar builds em pipelines de integração contínua

## Vantagens

- **Automação** – Perfeito para scripts e pipelines de CI/CD
- **Leve** – Não precisa carregar toda a IDE do Android Studio
- **Flexível** – Integra facilmente com outras ferramentas de linha de comando
- **Rápido** – Para tarefas repetitivas, a CLI geralmente é mais rápida que a GUI

## Documentação oficial

- [Android CLI – Documentação oficial](https://developer.android.com/tools/agents/android-cli)

## Quando usar

Prefira usar a Android CLI em vez do Android Studio quando:

- Você está automatizando builds em CI/CD
- Precisa executar comandos rapidamente sem abrir a IDE
- Está trabalhando em um servidor remoto ou container
- Quer integrar tarefas de Android em scripts de shell
